## Show HN
**Title:** Show HN: Rungs – a daily word ladder with checkpoints and golf scoring

**Body:**
I built a small daily puzzle: you get a START word and an END word (4 letters) and change one letter at a time to get there, but the ladder also has to pass through one or two checkpoint words. Par is computed by BFS over a curated word graph, so every puzzle is guaranteed solvable and scored golf-style (birdie, par, bogey).

No login, no ads, works on phone. Same puzzle for everyone each day, with an emoji share grid and a challenge-a-friend link that compares strokes.

Engine is plain TypeScript (word graph + BFS + seeded RNG), UI is React. Happy to answer questions about puzzle generation or difficulty tuning. I'd love feedback on par balance and the word list.
